# Проект: Автоматическая генерация и загрузка данных продаж в PostgreSQL

## Описание проекта

Проект автоматизирует ежедневный процесс:
- Генерация CSV-файлов с данными о продажах для N магазинов (каждый магазин может иметь несколько касс).  
  Формат имени файла: `{shop_num}_{cash_num}.csv`.
- Загрузка данных в базу данных PostgreSQL (таблица `sales`).
- Полная очистка таблицы перед каждой загрузкой (все старые данные удаляются).
- Удаление CSV-файлов после успешной загрузки.
- Работа по расписанию: **каждый день, кроме воскресенья** (проверка внутри скриптов).

## Состав проекта

| Файл | Назначение |
|------|-------------|
| `Upload_generation.py` | Генератор CSV-выгрузок. Создаёт папку `data/` и файлы `*_*.csv`. |
| `Uploading_database.py` | Загрузчик данных в PostgreSQL. Очищает таблицу, вставляет новые строки. |
| `run.py` | Промежуточный скрипт: проверяет день недели, наличие CSV-файлов, запускает загрузчик, удаляет файлы. |
| `start.bat` | (Windows) Пакетный файл для последовательного запуска генератора и `run.py`. |
| `config.ini` | Конфигурация подключения к PostgreSQL (создаётся вручную). |
| `requirements.txt` | Список зависимостей Python. |
## Подготовка окружения (новая машина)

### 1. Установите Python
- Скачайте Python версии **3.9 – 3.12** с [официального сайта](https://www.python.org/downloads/).
- При установке **обязательно** отметьте опцию **“Add Python to PATH”**.
- Проверьте установку в командной строке:
  ```cmd
  python --version
### 2. Создайте базу данных
- CREATE DATABASE sales_db;
### 3. Скачайте проект
- Скопируйте все файлы проекта в одну папку
### 4. Создайте виртуальное окружение
- venv\Scripts\activate
### 5. Установите зависимости
- pip install -r requirements.txt
### 6. Настройка подключения к базе данных
- Создайте в папке проекта файл config.ini
- [database]
- dbname = sales_db
- user = postgres
- password = ваш_пароль
- host = localhost
- port = 5432
### 7. Автоматизация (ежедневный запуск) для Windows (Планировщик задач)
- Настроить в Планировщике задач Windows запуск файла start.bat
